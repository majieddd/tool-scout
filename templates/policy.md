# Content & Abuse Policy

**Last updated:** {{LAST_UPDATED_DATE}}

## Inclusion

Tool Scout indexes tools from public sources: GitHub, npm, PyPI, MCP registries (PulseMCP, mcp.so, Smithery), curated awesome-* lists, and public posts on Reddit and Hacker News. Tools appear automatically based on public signals and matching keywords. There is no editorial process for inclusion.

## Takedown

Tool authors who wish to be removed may [open a takedown issue](../../issues/new?template=takedown.yml) with the tool URL. Removal is typically processed within 48 hours.

Removed tools are permanently excluded and **will not be re-added** on future crawls, even if the underlying source still indexes them.

## Wrapper requests

If a generated wrapper infringes a license or terms-of-use:

1. Open a takedown issue with the wrapper URL
2. The wrapper file will be deleted from the repository
3. The "Request wrapper" button on that tool's catalog page will be disabled

## Abuse

- Per-IP rate limit: 3 wrapper requests / 24 hours
- Global cap: 10 wrapper requests / 24 hours across all visitors
- Per-tool cap: 1 wrapper request / 24 hours per tool
- reCAPTCHA v3 verification required (threshold 0.5)
- Repeated abuse results in permanent IP blacklisting

## Content not allowed in catalog

Tool Scout will not index tools whose primary purpose is:

- Explicit harassment, doxxing, or hate
- Surveillance circumventing user consent
- Weapons, illegal substances, or other clearly illegal content
- Sexual content involving minors
- Malware (cryptominers shipped without disclosure, ransomware, etc.)

If you believe an indexed tool falls into one of these categories, open a takedown issue.
