# Privacy Policy

**Last updated:** {{LAST_UPDATED_DATE}}

## What we collect

- **IP address** — retained 30 days, hashed before database storage, used solely for rate limiting
- **Request timestamps** and tool IDs for wrapper requests
- **reCAPTCHA scores** (anonymous, via Google reCAPTCHA v3)
- **No cookies** except those required for site function

## What we do NOT collect

- Names, email addresses, or accounts (the service has none — there is no login)
- Browser fingerprints
- Any analytics about individual user behavior
- Anything else not strictly required for rate limiting and abuse prevention

## Third parties that see request metadata

- **Vercel** (hosting) — sees standard HTTP request metadata
- **Google** (reCAPTCHA) — sees the request and browser environment for scoring
- **ngrok** (tunnel) — sees request headers and body in transit between Vercel and the maintainer's machine
- **GitHub** (wrapper storage) — generated wrappers are stored in a public repository

These third parties have their own privacy policies. By using Tool Scout you also agree to those policies.

## Data deletion

To request deletion of logs covering a specific request you made, open a GitHub issue with the approximate timestamp window. Deletions are processed within 7 days.

Data older than 30 days is automatically purged via log rotation.

## Generated wrappers

Wrappers generated by this service are committed to a public GitHub repository. They are not associated with any user identity, but the wrapped tool's name and the timestamp of generation are visible in the commit history.
